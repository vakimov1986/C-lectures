    Ранній вихід із методу

    Ранній вихід завершує метод одразу, коли подальше виконання не має сенсу. Для цього використовують return.

    if (condition)
    return;

    Метод, який повертає значення, повинен указати його після return.

    if (score < 0 || score > 100)
    return "Invalid";

    Зменшення вкладеності

    Без раннього виходу основна логіка може опинитися всередині декількох вкладених блоків.

    public static string GetResult(int score)
{
    if (score < 0 || score > 100)
        return "Invalid";

    return score >= 50 ? "Pass" : "Fail";
}

    Такий підхід спочатку обробляє помилкові або особливі випадки, а потім залишає основний сценарій без зайвої вкладеності.
