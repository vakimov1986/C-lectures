# Тернарний оператор

Тернарний оператор `?:` обирає одне з двох значень залежно від умови.

```csharp
condition ? valueIfTrue : valueIfFalse
```

```csharp
string result = score >= 50 ? "Pass" : "Fail";
int max = a > b ? a : b;
string greeting = hour < 12 ? "Good morning" : "Good afternoon";
```

Тернарний оператор є виразом і повертає значення. Це відрізняє його від `if-else`, який керує виконанням блоків коду.

| Тернарний оператор | `if-else` |
| ------------------ | --------- |
| повертає значення | виконує блоки коду |
| зручний для простого вибору | підходить для декількох дій |
| записується одним виразом | може містити багато рядків |

Не варто вкладати багато тернарних операторів один в один: такий код складно читати. Для складної логіки використовуйте `if-else`.
