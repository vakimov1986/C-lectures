# Консольне виведення

`Console.WriteLine()` — це спосіб вивести текст у консоль у C#. Кожен виклик виводить текст і переводить курсор на новий рядок.

## Console.Write vs Console.WriteLine

У C# є два основні способи виведення тексту: `Console.WriteLine()` додає перехід на новий рядок після тексту, а `Console.Write()` залишає курсор у тому самому рядку.

## Ключові відмінності

| Метод | Додає новий рядок | Коли використовувати |
| --- | --- | --- |
| `Console.WriteLine()` | Так | Для виведення завершених рядків |
| `Console.Write()` | Ні | Для формування виведення частинами |

## Приклад

```csharp
Console.Write("Ім'я: ");
Console.WriteLine("Олена");
Console.WriteLine("Вітаємо у C#!");
```

Результат:

```text
Ім'я: Олена
Вітаємо у C#!
```
