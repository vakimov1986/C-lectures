# Цикл `do-while`

Цикл `do-while` спочатку виконує тіло, а потім перевіряє умову. Тому його тіло завжди виконується щонайменше один раз.

```csharp
do
{
    // Код виконується щонайменше один раз
} while (condition);
```

Зверніть увагу на крапку з комою після умови.

## `while` і `do-while`

```csharp
int x = 10;

while (x < 5)
{
    Console.WriteLine("Не виконається");
}
```

```csharp
int y = 10;

do
{
    Console.WriteLine("Виконається один раз");
} while (y < 5);
```

**Результат виконання:**

```text {.execution-result}
Виконається один раз
```

`do-while` підходить для меню, повторення спроби або введення даних, коли перша дія повинна відбутися до перевірки умови.
