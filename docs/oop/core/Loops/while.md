# Цикл `while`

Цикл `while` повторює блок коду, доки його умова залишається істинною. Його використовують, коли кількість повторень заздалегідь невідома.

```csharp
while (condition)
{
    // Тіло циклу
}
```

Умова перевіряється перед кожною ітерацією. Якщо вона одразу хибна, тіло циклу не виконається жодного разу.

```csharp
int counter = 1;

while (counter <= 3)
{
    Console.WriteLine(counter);
    counter++;
}
```

**Результат виконання:**

```text {.execution-result}
1
2
3
```

## Лічба вниз

```csharp
int counter = 5;

while (counter > 0)
{
    Console.WriteLine(counter);
    counter--;
}
```

**Результат виконання:**

```text {.execution-result}
5
4
3
2
1
```

## Нескінченний цикл

Якщо умова ніколи не стане хибною, цикл працюватиме нескінченно.

```csharp
int x = 1;

while (x <= 5)
{
    Console.WriteLine(x);
    // Відсутній x++, тому x завжди дорівнює 1
}
```

Завжди перевіряйте, що всередині циклу змінюються дані, від яких залежить його умова.
