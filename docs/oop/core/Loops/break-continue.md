# Оператори `break` і `continue`

Оператори `break` і `continue` змінюють звичайний перебіг циклу.

## `break`

`break` негайно завершує найближчий цикл.

```csharp
for (int i = 1; i <= 10; i++)
{
    if (i == 5)
        break;

    Console.WriteLine(i);
}
// 1, 2, 3, 4
```

Його використовують, коли результат уже знайдено або подальші ітерації не потрібні.

## `continue`

`continue` пропускає залишок поточної ітерації та переходить до наступної.

```csharp
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;

    Console.WriteLine(i);
}
// 1, 2, 4, 5
```

| Оператор | Результат |
| -------- | --------- |
| `break` | повністю завершує цикл |
| `continue` | пропускає лише поточну ітерацію |

У циклі `while` перед `continue` потрібно оновити дані, які впливають на умову, інакше можна випадково створити нескінченний цикл.
