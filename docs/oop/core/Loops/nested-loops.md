# Вкладені цикли

Вкладений цикл — це цикл усередині іншого циклу. Для кожної ітерації зовнішнього циклу внутрішній цикл виконує всі свої ітерації.

```csharp
for (int outer = 1; outer <= 3; outer++)
{
    for (int inner = 1; inner <= 3; inner++)
    {
        Console.Write($"({outer},{inner}) ");
    }

    Console.WriteLine();
}
```

**Результат виконання:**

```text {.execution-result}
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
(3,1) (3,2) (3,3)
```

## Таблиця множення

```csharp
for (int row = 1; row <= 3; row++)
{
    for (int column = 1; column <= 3; column++)
    {
        Console.Write($"{row * column} ");
    }

    Console.WriteLine();
}
```

**Результат виконання:**

```text {.execution-result}
1 2 3
2 4 6
3 6 9
```

Вкладені цикли використовують для таблиць, сіток, матриць, візерунків і порівняння кожного елемента з кожним. Загальна кількість виконань внутрішнього блока дорівнює добутку кількості ітерацій циклів.
