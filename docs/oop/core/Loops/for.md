# Цикл `for`

Цикл `for` використовують, коли кількість повторень відома або керується лічильником.

```csharp
for (ініціалізація; умова; ітерація)
{
    // Тіло циклу
}
```

1. Ініціалізація виконується один раз.
2. Умова перевіряється перед кожною ітерацією.
3. Зміна лічильника виконується після кожної ітерації.

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
```

**Результат виконання:**

```text {.execution-result}
0
1
2
3
4
```

## Лічба вниз

```csharp
for (int i = 5; i >= 1; i--)
{
    Console.WriteLine(i);
}
```

**Результат виконання:**

```text {.execution-result}
5
4
3
2
1
```

## Інший крок лічильника

```csharp
for (int i = 2; i <= 10; i += 2)
{
    Console.WriteLine(i);
}
```

**Результат виконання:**

```text {.execution-result}
2
4
6
8
10
```

Використовуйте `for`, коли керування лічильником природно описує цикл. Якщо кількість повторень залежить від події або введення, частіше підходить `while`.
