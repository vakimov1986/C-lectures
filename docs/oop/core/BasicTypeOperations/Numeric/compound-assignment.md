# Складені оператори присвоєння

Складені оператори поєднують арифметичну операцію з присвоєнням нового значення тій самій змінній.

```csharp
int score = 10;

score = score + 5;
score += 5; // коротший запис тієї самої дії
```

---

## Основні оператори

| Оператор | Повний запис | Опис |
| -------- | ------------ | ---- |
| `+=` | `x = x + value` | додати та присвоїти |
| `-=` | `x = x - value` | відняти та присвоїти |
| `*=` | `x = x * value` | помножити та присвоїти |
| `/=` | `x = x / value` | поділити та присвоїти |
| `%=` | `x = x % value` | обчислити остачу та присвоїти |

```csharp
int x = 20;

x += 5; // 25
x -= 3; // 22
x *= 2; // 44
x /= 4; // 11
x %= 4; // 3
```

---

## Послідовне застосування

Кожен оператор використовує поточне значення змінної.

```csharp
int result = 10;

result += 5; // 15
result -= 3; // 12
result *= 2; // 24
result /= 4; // 6
```

Складені оператори змінюють саму змінну, тому вона не може бути оголошена з ключовим словом `const`.
