# Інкремент і декремент

Оператор інкременту `++` збільшує значення змінної на `1`, а оператор декременту `--` зменшує його на `1`.

```csharp
int score = 5;

score++; // 6
score--; // 5
```

Обидва оператори мають префіксну та постфіксну форми.

---

## Постфіксна форма

У постфіксній формі оператор розташований після змінної. У виразі спочатку використовується старе значення, а потім змінна змінюється.

```csharp
int x = 5;
int result1 = x++; // result1 = 5, x = 6

int y = 10;
int result2 = y--; // result2 = 10, y = 9
```

---

## Префіксна форма

У префіксній формі оператор розташований перед змінною. Спочатку значення змінюється, а потім використовується у виразі.

```csharp
int x = 5;
int result1 = ++x; // result1 = 6, x = 6

int y = 10;
int result2 = --y; // result2 = 9, y = 9
```

---

## Порівняння форм

| Оператор | Назва | Значення виразу, якщо `x = 5` | Нове значення `x` |
| -------- | ----- | ----------------------------- | ----------------- |
| `x++` | постінкремент | `5` | `6` |
| `++x` | преінкремент | `6` | `6` |
| `x--` | постдекремент | `5` | `4` |
| `--x` | предекремент | `4` | `4` |

Якщо значення операції ніде не використовується, префіксна й постфіксна форми дають однаковий результат:

```csharp
x++;
++x;
```
