# Арифметичні оператори

Арифметичні оператори виконують математичні дії над числовими значеннями.

| Оператор | Операція | Приклад | Результат |
| -------- | -------- | ------- | --------- |
| `+` | додавання | `10 + 3` | `13` |
| `-` | віднімання | `10 - 3` | `7` |
| `*` | множення | `10 * 3` | `30` |
| `/` | ділення | `10 / 3` | `3` для типу `int` |
| `%` | остача від ділення | `10 % 3` | `1` |

---

## Базові операції

```csharp
int a = 10;
int b = 3;

int sum = a + b;        // 13
int difference = a - b; // 7
int product = a * b;    // 30
int quotient = a / b;   // 3
int remainder = a % b;  // 1
```

Під час ділення двох значень типу `int` результат також має тип `int`, тому дробова частина відкидається.

```csharp
int integerResult = 10 / 3;       // 3
double preciseResult = 10.0 / 3;  // 3.333...
```

---

## Остача від ділення

Оператор `%` повертає остачу після ділення.

```csharp
int remainder = 17 % 5;     // 2
int noRemainder = 10 % 2;   // 0
int smallerNumber = 3 % 7;  // 3
```

Ділення та остача пов’язані формулою:

```text
ділене = частка * дільник + остача
17 = 3 * 5 + 2
```

---

## Поширені застосування `%`

```csharp
bool isEven = number % 2 == 0; // парне число
bool isOdd = number % 2 != 0;  // непарне число
int lastDigit = number % 10;   // остання цифра
int cyclicIndex = index % arrayLength;
```

Ділення або обчислення остачі від нуля для цілих чисел спричиняє помилку виконання `DivideByZeroException`.
