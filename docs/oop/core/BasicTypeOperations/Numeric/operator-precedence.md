# Порядок виконання операцій

Коли вираз містить кілька операторів, C# виконує їх відповідно до пріоритету. Множення, ділення та остача від ділення мають вищий пріоритет, ніж додавання і віднімання.

---

## Пріоритет арифметичних операторів

| Пріоритет | Оператори | Опис |
| --------- | --------- | ---- |
| 1 — найвищий | `( )` | вираз у дужках |
| 2 | `*`, `/`, `%` | множення, ділення, остача |
| 3 | `+`, `-` | додавання, віднімання |

```csharp
int result1 = 2 + 3 * 4;   // 14
int result2 = 10 - 6 / 2;  // 7
int result3 = 8 / 4 * 2;   // 4
```

Оператори з однаковим пріоритетом у цих виразах виконуються зліва направо.

---

## Використання дужок

Дужки змінюють стандартний порядок виконання.

```csharp
int result1 = (2 + 3) * 4;  // 20
int result2 = (10 - 6) / 2; // 2
int result3 = 10 / (2 + 3); // 2
```

Навіть коли дужки не змінюють результат, їх можна використовувати, щоб зробити складний вираз зрозумілішим.

```csharp
int result = (a + b) * c;
int ratio = (a + b) / (c + d);
```
