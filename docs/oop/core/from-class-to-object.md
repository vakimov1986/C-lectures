# Від класу до об'єкта

У цій лекції ми поступово створимо клас `Person`, навчимося створювати об'єкти, працювати з полями та викликати методи. На кожному кроці будемо змінювати один і той самий приклад.

> **Мета:** навчитися створювати клас та об'єкт, розрізняти поле й локальну змінну, записувати і зчитувати стан об'єкта за допомогою методів.

## 1. Створення порожнього класу

Клас описує тип об'єктів: які дані вони можуть зберігати та які дії виконувати. Спочатку створимо клас без жодного члена:

~~~csharp
public class Person
{
}
~~~

- `class` — ключове слово для оголошення класу.
- `Person` — назва класу.
- `{ }` — тіло класу; поки воно порожнє.

**Зверніть увагу:** оголошення класу ще не створює об'єкт.

## 2. Створення об'єкта

У методі `Main` створимо об'єкт класу `Person`:

~~~csharp
Person person = new Person();
~~~

Розглянемо складові цього запису:

| Частина | Значення |
| --- | --- |
| `Person` зліва | Тип змінної |
| `person` | Назва змінної |
| `=` | Оператор присвоєння |
| `new Person()` | Вираз, який створює об'єкт та повертає посилання на нього |

`Person` — посилальний тип. Змінна `person` зберігає **посилання на створений об'єкт**, а не сам об'єкт безпосередньо.

### Повний приклад

~~~csharp
public class Person
{
}

public class Program
{
    public static void Main()
    {
        Person person = new Person();
    }
}
~~~

**Перевірте себе:** де в рядку `Person person = new Person();` зазначено тип змінної, її назву та вираз, результат якого їй присвоюється?

## 3. Оператор `new` і конструктор

Оператор `new` у виразі `new Person()` створює екземпляр класу та викликає його конструктор.

**Конструктор** — спеціальний метод класу, який викликається під час створення об'єкта та може виконувати його початкову ініціалізацію.

Особливості конструктора:

- його назва збігається з назвою класу;
- він не має оголошеного типу повернення, навіть `void`;
- може приймати параметри.

У нашого порожнього класу `Person` немає явно оголошеного конструктора, тому компілятор надає доступний конструктор без параметрів.

Можна оголосити конструктор самостійно:

~~~csharp
public class Person
{
    public Person()
    {
    }
}
~~~

Тепер вираз `new Person()` викликає саме цей конструктор.

> Якщо в класі оголошено власний конструктор із параметрами, компілятор уже не додасть автоматично конструктор без параметрів.

## 4. Додаємо поле

Об'єкту потрібно зберігати вік людини. Для цього додамо поле `Age`:

~~~csharp
public class Person
{
    public int Age;
}
~~~

**Поле** — змінна, оголошена безпосередньо в класі або структурі (поза методами). Поле екземпляра зберігає частину стану конкретного об'єкта.

Поки поле має модифікатор доступу `public`, звернутися до нього можна ззовні класу:

~~~csharp
Person person = new Person();
person.Age = 20;

Console.WriteLine(person.Age);
~~~

Тут `person.Age = 20;` записує значення в поле об'єкта, а `Console.WriteLine(person.Age);` виводить це значення.

## 5. Поле та локальна змінна

Порівняємо поле класу й локальну змінну методу:

~~~csharp
public class Person
{
    public int Age; // Поле

    public void ShowExample()
    {
        int number = 10; // Локальна змінна
        Console.WriteLine(number);
    }
}
~~~

| Ознака | `Age` | `number` |
| --- | --- | --- |
| Де оголошено | У тілі класу, поза методом | Усередині методу |
| Що представляє | Частину стану об'єкта | Дані, потрібні для виконання методу |
| Де можна звертатися | Відповідно до модифікатора доступу | У межах своєї області видимості |
| Чи зберігається між викликами методу | Так, поки існує об'єкт | Ні, це окрема локальна змінна кожного виклику |

Поле також є змінною. Тому правильно порівнювати **поле** саме з **локальною змінною**, а не зі «змінною взагалі».

## 6. Чому не варто відкривати поле

Зараз будь-який код, який має доступ до об'єкта, може змінити його вік напряму:

~~~csharp
person.Age = -100;
~~~

Такий запис компілюється, хоча від'ємний вік для нашої моделі не має сенсу.

Публічне поле не дозволяє класу контролювати всі зовнішні присвоєння. Тому для внутрішнього стану об'єкта зазвичай використовують закриті поля та надають доступ до них через методи або властивості.

Почнемо з методів. Зробимо поле закритим:

~~~csharp
public class Person
{
    private int _age;
}
~~~

Тепер звернення `person._age = 20;` із методу `Main` не допускається.

## 7. Метод для запису значення

Створимо відкритий метод `SetAge`, який дозволить змінювати закрите поле:

~~~csharp
public class Person
{
    private int _age;

    public void SetAge(int age)
    {
        _age = age;
    }
}
~~~

Розберімо **заголовок методу** `public void SetAge(int age)`:

| Частина | Значення |
| --- | --- |
| `public` | Модифікатор доступу |
| `void` | Метод не повертає значення |
| `SetAge` | Назва методу |
| `int age` | Параметр: тип `int`, назва `age` |

`age` — параметр, через який метод отримує дані від коду, що його викликає. `_age` — поле, у яке метод записує отримане значення.

Викличемо метод:

~~~csharp
Person person = new Person();
person.SetAge(20);
~~~

Число `20` тут — **аргумент виклику**. Метод отримує його через параметр `age`.

> Тип повернення `void` не означає «немає вхідних параметрів». Метод `SetAge` має один параметр, але не повертає значення. Не слід плутати значення, яке повертає метод, із параметром `out` — це різні механізми C#.

## 8. Метод для читання значення

Тепер потрібен спосіб прочитати закрите поле. Додамо `GetAge`:

~~~csharp
public class Person
{
    private int _age;

    public void SetAge(int age)
    {
        _age = age;
    }

    public int GetAge()
    {
        return _age;
    }
}
~~~

Метод `GetAge`:

- має тип повернення `int`;
- не приймає параметрів;
- повертає значення поля `_age` за допомогою оператора `return`.

Викличемо метод, збережемо його результат у локальній змінній та виведемо на екран:

~~~csharp
Person person = new Person();
person.SetAge(20);

int age = person.GetAge();
Console.WriteLine(age);
~~~

Після виклику `person.GetAge()` локальна змінна `age` міститиме значення `20`.

## 9. Повний приклад

Усі кроки об'єднаємо в одну програму:

~~~csharp
public class Person
{
    private int _age;

    public void SetAge(int age)
    {
        _age = age;
    }

    public int GetAge()
    {
        return _age;
    }
}

public class Program
{
    public static void Main()
    {
        Person person = new Person();

        person.SetAge(20);

        int age = person.GetAge();
        Console.WriteLine(age);
    }
}
~~~

**Результат виконання:**

~~~text
20
~~~

У цьому прикладі `_age` є полем об'єкта, `age` у методі `Main` — локальною змінною, `SetAge` записує значення, а `GetAge` його повертає.

## 10. Завдання для самоперевірки

Виконайте кроки самостійно, не копіюючи готовий клас:

1. Оголосіть порожній клас `Book`.
2. Створіть об'єкт класу `Book`. Поясніть тип, назву й значення змінної.
3. Додайте публічне поле `Pages` типу `int`, запишіть у нього число `150`.
4. Створіть у класі метод із локальною змінною. Поясніть відмінність від поля.
5. Змініть поле `Pages` на закрите `_pages`.
6. Напишіть метод `SetPages(int pages)`, який записує значення в поле.
7. Напишіть метод `GetPages()`, який повертає значення поля.
8. У методі `Main` викличте обидва методи. Результат `GetPages()` збережіть у локальну змінну та виведіть у консоль.

**Підсумок.** Ви навчилися оголошувати класи, створювати об'єкти, розрізняти поля й локальні змінні та керувати станом об'єкта через методи. У наступній темі розглянемо, як властивості (`get` і `set`) дозволяють зручніше організувати доступ до поля.
