# Тип `string`

Тип `string` використовується для зберігання текстових даних. Текст може містити літери, цифри, пробіли та спеціальні символи.

Значення типу `string` записуються в подвійних лапках.

---

## Оголошення рядків

Рядкові значення записують у подвійних лапках.

```csharp
string name = "Alice";
string city = "New York";
string message = "Order #12345 confirmed!";
string empty = "";
```

---

## `string` vs числові типи

```csharp
int age = 25;          // число — без лапок
double price = 19.99;  // число — без лапок
string name = "Bob";  // текст — у подвійних лапках
```

---

## Доступ до символів рядка

Кожен символ рядка має свій **індекс**, починаючи з `0`. Для отримання символу використовують квадратні дужки `[]`. Результат має тип `char`.

```csharp
string language = "CSharp";

char first = language[0];  // 'C'
char second = language[1]; // 'S'
```

## Незмінність рядків

Рядки в C# є **незмінними** (immutable). Це означає, що символи вже створеного рядка не можна змінити.

```csharp
language[0] = 'B'; // Помилка компіляції
```

Операції, які змінюють вміст рядка, насправді створюють новий рядок.

```csharp
string greeting = "Hello";
greeting = greeting + "!"; // Новий рядок "Hello!"
```

**Важливо:** незмінність рядка не забороняє присвоювати змінній `string` нове значення.
