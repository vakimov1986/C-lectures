# Тип `bool`

Тип `bool` представляє логічне значення, яке може бути лише `true` або `false`. Логічні значення використовують для перевірки умов і прийняття рішень у програмі.

---

## Оголошення змінних типу `bool`

```csharp
bool isActive = true;
bool isComplete = false;
bool hasPermission = true;
```

Значення типу `bool` також є результатом порівнянь і логічних операцій. Самі оператори розглядаються окремо на сторінці [«Логічні операції»](../BasicTypeOperations/logical-operations.md).
