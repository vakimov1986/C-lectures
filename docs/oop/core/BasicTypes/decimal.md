# Тип `decimal`

Тип `decimal` використовується для десяткових чисел із високою точністю. Він особливо зручний для фінансових обчислень, де важливо уникати похибок, характерних для чисел із плаваючою комою.

У C# `decimal` — це **128-бітне десяткове число**, тобто для зберігання значення використовується **128 біт (16 байтів)** пам’яті.

---

## Оголошення змінних типу `decimal`

До числового літерала потрібно додати суфікс `m` або `M`.

```csharp
decimal price = 19.99m;
decimal taxAmount = 1.60m;
decimal balance = -125.50m;
```

---

## `decimal` vs `double`

`double` зазвичай використовують у наукових розрахунках і графіці, де допустимі невеликі похибки. `decimal` краще підходить для грошей та інших значень, для яких важлива десяткова точність.

```csharp
double distance = 3.14159265358979;
decimal price = 19.99m;
```

---

## Базові математичні операції

```csharp
decimal price1 = 19.99m;
decimal price2 = 5.50m;

decimal total = price1 + price2;      // 25.49
decimal difference = price1 - price2; // 14.49
decimal doubled = price1 * 2;         // 39.98
```

---

## Коли використовувати `decimal`

Тип `decimal` підходить для:

* цін і грошових сум
* податків, відсотків і знижок
* бухгалтерських та фінансових розрахунків
* значень, для яких критична десяткова точність
